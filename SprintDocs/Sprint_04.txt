Sprint 04: Bright main menu
Date: 2026-11-05
Unity: 6000.3.27f2
Status: Complete.

Goals
- Start the scene at a bright menu matching the existing wheel artwork.
- Add Play, Quit, and a return-to-menu button.
- Support portrait, landscape, square screens, safe areas, and short windows.
- Preserve the last result when moving between menu and gameplay.

Changes
- Added WheelMenuController to switch the menu and game roots.
- Registered button listeners while the controller is enabled and removed them on disable.
- Selected Play or Spin when opening each screen for UI navigation.
- Prevented returning to the menu during an active spin.
- Quit stops Play mode in the Editor and calls Application.Quit in a player build.
- Added WheelMenuLayout to position and scale menu content inside the display safe area.
- Added vertical scrolling when the menu is taller than the available space.
- Reused the existing gold frame, pointer, pastel wheel, panel, button, and font assets.
- Added a reserved navigation row to the existing game layout for the Menu button.
- Added an editor command to install and save the menu without replacing the existing game.
- Extended existing validation to cover menu startup, navigation, layout, and preserved results.
