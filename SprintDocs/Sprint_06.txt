Sprint 06: Responsive WebGL page and audible roulette ticks
Date: 2026-11-05
Unity: 6000.3.27f2
Status: Complete.

Goals
- Replace the fixed desktop WebGL canvas with a page that fills the browser.
- Restore short click and tick effects in the exported player.
- Rebuild and verify the actual browser version.

Problems found
- The exported default template fixed the desktop canvas at 960x600.
- The tick was assigned and requested during spins, but the browser-decoded
  audio buffer had a peak of only 0.002389 versus 0.911490 in the OGG source.
- The original 8.7 ms click decoded to silence in the exported build.
- These very short effects lost their attacks during WebGL audio conversion.

Changes
- Added a persistent Responsive WebGL template under Assets/WebGLTemplates.
- Canvas CSS fills the available browser viewport and reserves safe-area insets.
- Enabled Unity canvas-to-render-target size matching.
- Used one render pixel per CSS pixel so the existing minimum UI scale maps
  consistently to visible controls on high-density displays.
- Added padded PCM WAV variants of click and tick: 50 ms leading silence and
  75 ms trailing silence, with DecompressOnLoad and audio preloading enabled.
- Assigned the WAV variants to the saved scene.
- Added Prepare Web Build and Build Web Player editor menu commands.
- Kept the existing wheel animation and audio event timing.
- Added asset credits, hosting instructions, and licenses to the distribution.

Open questions and technical debt
- Physical mobile devices, Safari, and Firefox were not tested.
- High-density displays intentionally render at one pixel per CSS pixel;
  this trades additional rendering sharpness for consistent controls and cost.
- The build reported 345 shader warnings from the existing AI inference/Sentis
  package: ConvGeneric (320), ScatterND (9), ConvTranspose (6), SliceSet (4),
  GridSample (3), ScatterElements (2), and Pad (1). No game C# warning was found.
  Package cleanup is outside this responsive/audio fix.
- Hosting must send the Brotli headers listed in README.txt.
- The local preview requires its local server to remain running.
