Sprint 05: Main menu and navigation
Date: 2026-11-05
Unity version: 6000.3.27f2

Goals
- Open the game on a main menu with Play and Quit.
- Start a fresh round from Play.
- Return to the menu from gameplay and clear the current round.

Changes
- Added a menu using the existing colors, typography, and watermelon backdrop.
- Grouped the round display and gameplay buttons separately from the menu.
- Added Play, Quit, and an in-game Menu button.
- Play resets the count, multiplier, deformation, fragments, and sounds.
- Menu clears the round and restores the whole watermelon as the backdrop.
- Band input is blocked while the menu is displayed.
- Selected Play or Add Band when switching screens for UI navigation.
- Quit stops Play Mode in the Editor and calls Application.Quit in builds.
- Updated scene creation to include the menu in newly generated scenes.
- Added Watermelon > Set Up Main Menu to configure the existing scene.
- Extended the existing round-flow check to cover Play and Menu navigation.

How to use
1. Open Assets/Scenes/Watermelon.unity and press Play in Unity.
2. Press the on-screen Play button to begin a round.
3. Use Menu near the upper right of the game screen to return to the main menu.
4. Use Quit on the main menu to leave the application or Editor Play Mode.
