Sprint 03: Responsive screen layout
Completed: 2026-11-05
Unity: 6000.3.6f1 implementation; 6000.3.27f2 final spin and manual checks.
Status: Complete.

Goals
- Adapt the wheel and result panel to portrait, landscape, and square screens.
- Respect safe areas and keep controls reachable in short windows.
- Preserve artwork proportions, pointer alignment, and readable labels.

Changes
- Added WheelResponsiveLayout with explicit Inspector references.
- Grouped the wheel, pointer, and hub for uniform scaling.
- Stack the wheel and panel on narrow screens; place them beside each other on wide screens.
- Bound content width on ultrawide displays.
- Apply safe-area anchors and clipped vertical scrolling when needed.
- Keep the Spin button at least 44 pixels tall at the minimum UI scale.
- Adjust multiplier label size and verify spacing between neighboring labels.
- Recalculate layout when screen size or safe area changes.
- Updated scene creation and artwork application for the responsive hierarchy.
- Added actual Game view resolution validation and preview captures.
