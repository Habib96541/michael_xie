# Asset provenance

- All machine, object and fracture meshes are original procedural artwork authored in ModelGeometry.cs and ContentBuilder.cs for this project.
- All icons are original line artwork generated by Tools/create_media.py.
- All fifteen WAV assets are original deterministic synthesis generated by Tools/create_media.py. No recorded or downloaded sound samples are used.
- Text uses Liberation Sans supplied with Unity TextMesh Pro Essential Resources. Its license is preserved alongside the original font under Assets/TextMesh Pro/Fonts.
- Unity URP, Input System, uGUI, TextMesh Pro and Test Framework are used under their accompanying package licenses.
- No paid asset service or remotely generated art was used.
