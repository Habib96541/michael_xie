HYDRAULIC PRESS

Run Play Hydraulic Press.cmd (Python 3 required).
Or run python serve.py and visit http://localhost:8088.

Choose PLAY from the main menu. CRUSH to continue. CASH OUT to bank.
Tap pause or press Escape for RESUME / SETTINGS / MAIN MENU.
Phone: portrait and landscape supported. Virtual points only.

For other hosting, serve .gz files with Content-Encoding: gzip and
original MIME types: .wasm.gz = application/wasm, .js.gz = application/javascript.
Do not open index.html directly via file://.
