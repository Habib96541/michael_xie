Illustrations
-------------
Art/Brand/MineGridLogo.png, GoldCoin.png, CyanGem.png, NavyMine.png:
Created for this project with the built-in image_gen tool on 31 October 2026.
No external reference artwork or third-party logo was copied into these assets.
Generated PNG alpha is retained; Unity imports them as single sprites with
preserved aspect ratios, bilinear filtering, no mipmaps, and no compression.
Original generation files remain in the Codex generated_images folder; the game
uses the copies inside Assets. No API key or fallback generation CLI was used.
Generation prompts are saved in Art/Brand/GenerationPrompts.txt.

UI surfaces, hidden/safe/mine tile backgrounds, backdrop, wheel, and decoration
are generated by Assets/Editor/MineGridSetup.cs. Gameplay illustrations are
separate from tile backgrounds so they remain proportionate and reusable.

Shared theme
------------
UITheme.asset holds fonts, sprites, and core colors. GameConfig.asset remains
responsible for gameplay and economy. Regenerating the scene preserves the
branding imports and uses the shared theme. Six wheel segments remain required.
