Explanation and concepts learned
- Web Build Support supplies the matching browser toolchain; the build profile defines target/player settings.
- IL2CPP compiles game code into WebAssembly. The loader, framework and data must travel with index.html.
- File/ZIP/HTTP checks establish integrity and delivery; browser playtesting establishes rendering and interactions.
