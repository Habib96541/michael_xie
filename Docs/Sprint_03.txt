Sprint 03: Add neon feedback to Flap Dash
Status: implementation verified; user style review and understanding pending.

Goals
- Make Flap Dash visually reactive while preserving the movement tuning the user liked.
- Keep decorative animation separate from physics, colliders, score, and input timing.
- Use verified public-domain outsourced content and record its provenance.

Changes
- Added PlayerFeedback: wing motion, squash/stretch, tilt, glow, trail, and flap particles.
- Added RoundFeedback: score pop, panel entrance animation, and passage/impact particles.
- Added ButtonFeedback: hover, selection, press, and submit responses.
- Added VisualEffectsSettings: a Ready/Results intensity slider, retained within the app session.
- Connected feedback using Inspector references and a reset hook in RoundController.
- Retained flap speed 7, gravity scale 1.5, player radius 0.3, authored course, one point per pipe, and 60-second limit.
- Replaced default LiberationSans with creator-dedicated public-domain Tuffy. Removed default font/fallback and EmojiOne content from Assets. Unity/TMP software still retains its original license.
- Created project-owned glow art and used built-in particles; no outside art/audio/animation package was needed.

Debugging lesson
- The first new-font setup encountered a null fallback-font list. Read the exception line and guarded the optional list before clearing it.
- A rapid end/restart within one frame exposed a missed UI state transition. Clear effects directly at the round reset boundary rather than relying only on the next UI refresh.

Concepts learned
- Animate child visual transforms instead of the Rigidbody/collider root.
- Use unscaled time for short presentation feedback without changing simulation time.
- Keep settings in a single referenced component rather than introduce global/shared-game state.
- Clear transient particles and trails when their round ends/restarts.
- Free price, public-domain content and software licensing are separate concepts.

Senior note
- A visual-only feature can still break gameplay if it changes collider scale, blocks input, obscures targets, or leaves state after restart. Verify those boundaries explicitly.

Learn more
- Unity Manual concept: Transform parenting and local coordinates. Local scale on a visual child can change its appearance while its parent's collider stays unchanged.
