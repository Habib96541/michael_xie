Sourcing rule
Externally sourced game content must be verified CC0/public domain using the original creator source and archive license. Record exact files, source, creator, version/hash, modifications and evidence. A free price or royalty-free label alone is insufficient. Keep a separate record inside each independent project that uses a resource.
