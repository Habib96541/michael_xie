Debugging lesson
- The first native render showed the slider fill wider than its track. Its RectTransform had a fixed width as well as stretched anchors driven by Slider, which added both widths. Set the fill's sizeDelta to zero; a new bounds check now detects this regression.
- Cloud layers contained an opaque base color, so their bottom edges showed a hard seam against a different camera color. Inspecting the source pixel color identified the mismatch; matching the camera background removed it.
- The supplied background layers are light blue by default. Renderer tints create the approved green hills without changing the original asset pixels.

Explanation
- A sprite is a Unity reference to an image or a region of one. Bird animation swaps among eight assigned sprites; the Rigidbody remains on the parent object.
- A pipe's artwork is a child of its collision object. Its visual proportions can change without resizing the parent's explicitly configured collider.
- Sliced UI images preserve border/corner regions while stretching their center. Keep layout anchors and sizeDelta consistent so the stretched image stays inside its track.
- Visual Energy scales optional bird/cloud motion. The gameplay timing and collision code do not read it.

Senior note
- Imported sprite bounds include transparent padding and can differ between files. Never let new art silently redefine colliders. Preserve source notices and inspect the actual assembled scene, not only the source previews.

Learn more
- Unity concept: sliced UI sprites (nine-slice scaling), sprite borders and RectTransform anchors.
