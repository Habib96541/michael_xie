Sprint 06 proposal: Bird chirp on flap
Status: approved with the user's selected fourth source-page preview and implemented on 2026-11-02. All 30 checks pass; listening quality and user understanding remain pending. See Sprint_06.txt.

Why
The user wants a bird sound when pressing to fly. Trigger sound from the accepted flap action so keyboard, mouse and touch stay consistent, and holding the button does not repeat it.

Proposed behavior
- One soft approximately 0.206-second chirp for each accepted flap, using the fourth preview selected by the user.
- Use a single 2D AudioSource on Player, playOnAwake false, loop false, spatialBlend 0 and initial volume 0.3.
- Retrigger the same source on rapid presses rather than layer simultaneous voices.
- Stop the sound when the round ends or the player resets.
- Menu clicks and rejected input do not chirp.
- Keep sound independent of Visual Energy, which controls decorative motion only.
- Add exactly one active AudioListener on Main Camera; the current FlapDash scene has none.
- Do not change movement, physics, scoring, artwork or round duration. Do not rebuild WebGL.
