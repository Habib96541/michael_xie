Sprint 12: Show the countdown during gameplay
Date: 2026-11-02
Status: approved source and scene changes implemented; static checks pass. Unity compilation, visual/play checks and user understanding pending.

Goals and why
- Restore the missing gameplay timer while keeping the score centered in its header.
- Use the existing round state to control visibility. Text content and GameObject visibility are separate concerns: updating text does not activate a disabled object.
- Show a small countdown below the header during Playing; hide it on Ready and Results.

Approved plan and done condition
- RoundView.cs controls Timer visibility alongside Score.
- FlapDash.unity positions the existing Timer below the score header.
- This record explains changes and manual checks.
- User approved before code changes. Done when the timer counts down during play, hides on menus and resets to 60 seconds on restart, with no overlap or Console errors. Runtime and learning acceptance remain pending.

- Timer remains a Header child, centered at anchored position (0, -70), size (200, 32), with centered 24-point text. The header remains active, so the timer can render below its panel.
- Initial saved text is TIME 60s. Initial Ready visibility remains inactive; RoundView activates it during Playing.
- No new objects, fields, assets or packages. No gameplay, course, audio, prefab, generator or build changes.

Manual checks for the user
1. Exit Play mode. Preserve unsaved scene edits before reloading external changes; do not regenerate the scene. If merging manually, use the Timer layout values above and keep its existing Time Label assignment.
2. Let Unity compile and check the Console. Ready should show FLAP DASH with no countdown.
3. Choose START ROUND. Confirm the title becomes the centered score and TIME 60s appears below it, then decreases without overlapping the score.
4. Finish a round. Confirm the timer hides on Results. Choose PLAY AGAIN and confirm it reappears at 60 seconds, while the score and speed reset.
5. Confirm timeout still ends the round. Report visual overlap, clipping or any exact Console error. The actual countdown logic was not changed.

Senior note
