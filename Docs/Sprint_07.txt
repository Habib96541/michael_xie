Explanation
- Inspector fields store references to specific components. An object with the same name is not automatically linked.
- The title inside the round panel is now optional. The static header does not need to be assigned to that field.
- Renaming or moving an assigned object normally preserves its reference. Removing/replacing it or clearing the field can leave the old slot empty.
