ACCEPTANCE / SCOPE

collisions, 8–16 rows (12 default), R+1 physical pockets, 50 pooled independent
balls, rapid discrete drops, Green/Gold/Red profiles, 1/5/10/25/50 amounts,
1,000 starting coins, durable pending transactions, interruption refunds,
home/game/settings/help, responsive WebGL page and local HTTP delivery.

No real money, purchases, auto-drop, music, vibration, shops or metagame.

BOARD RULES
For row r=0..R-1, generate r+1 pegs at x=c-r/2, y=R-r+1, c=0..r.
Pocket i=0..R is centered x=i-R/2, trigger y=0.65. Bottom pegs align with
separators between pockets. Peg spacing is 1 world unit horizontally/vertically.
Outer boundaries are vertical; bottom dividers prevent crossing pocket sensors.
An orthographic camera frames geometry independently of overlay UI.
Viewport changes only camera and UI, never the active physics geometry.
Portrait multiplier labels alternate vertically to preserve label width.

REWARDS / ROUNDING
Each row/profile table is stored as R+1 integer hundredths in GameConfig.asset.
Tables were authored once with e=abs(2*i/R-1):
  Green: round(70 + 130*e^2), range 0.70x–2.00x.
  Gold:  round(40 + 760*e^3), range 0.40x–8.00x.
  Red:   round(15 + 2485*e^5), range 0.15x–25.00x.
Odd row counts have two central values slightly above each formula's minimum.
Actual serialized integer values are authoritative; build only validates them.
Intended arcade balancing: Green flatter, Gold intermediate, Red edge-heavy.
No casino-equivalent odds, expected return or fairness-verification claims.
Wallet and amounts use long integer hundredths of a virtual coin.
Payout in hundredths = (reservedHundredths * multiplierHundredths + 50)/100,
using integer division: nearest hundredth, ties rounded upward.
Per-ball transaction clones the table, cost, row count and profile.

PHYSICS / POOLING
Only Rigidbody2D/Collider2D; no gameplay 3D physics.
Ball diameter 0.28, peg diameter 0.21 world units. Gravity scale 1.6.
PhysicsMaterial2D friction .05, restitution .58, Continuous collision detection,
interpolated rigidbodies. Ball layer 8 ignores itself. Pool capacity 50.
Spawn x uniform [-.16,.16], y=R+2.1, symmetric, zero initial velocity.
Timeout 35 seconds; speed squared below .01 for 4 seconds is stuck.
Escaped if y<-3 or abs(x)>13. These conditions refund rather than reward.
Every launch resets velocity, angular velocity, age, stuck timer, transform,
color and transaction. Terminal state guards duplicate triggers and pool reuse.
No animation callback owns rewards. Results history capped at 5 entries.
Settings and leave modals block all Drop activations; physics can continue.
Leaving with active balls offers Stay or Home when clear; draining blocks drops.
Focus loss/suspension freezes simulation; resume restores simulation.

SAVE SCHEMA / INTERRUPTIONS
Browser key: PegRush.Save.v1, same-origin localStorage, synchronous writes.
JSON: Version=1; Coins (hundredths); Muted; Reduced; Pending array.
Pending entries: stable GUID Id, Amount, Rows, Profile, cloned Table.
Reserve persists deduction plus pending entry before spawn/feedback.
Resolve persists removal plus credit before result effects/recycle.
On reopening, unresolved valid pending amounts refund once; pending clears in
that same save. Completed rewards remain in Coins. No pending landing rewards
are reconstructed or awarded. Invalid/missing/outdated saves reset to 1,000.
Failed writes reject reservations without charge; failed settlement retains the
pending transaction for retry/recovery. Editor uses PlayerPrefs instead.
Browser storage is local to origin, browser and profile; not a cloud account,
not tamper-resistant. Clearing site data/private sessions/storage restrictions
can erase progress or disable saving. No reliance on unload or quit callbacks.

ASSETS / LICENSES
All PegRush artwork is original procedural C# output: 64x64 RGBA orb and
rounded rectangle. Center pivots, bilinear filtering, no mipmaps, lossless sprite
imports. Rounded panel borders are 14 pixels and use Image.Type.Sliced.
No source art overwritten; generation source remains in PegRushAuthoring.cs.
Text uses Unity's builtin LegacyRuntime font. Audio is an original synthesized
sine chime. Existing Unity template/package assets retain their own licenses.
No third-party art or copied branding.

BUILD / RUN / DEPLOY
Use Unity 6000.3.10f1 with WebGL module and an active Unity license.
Open Assets/PegRush/Generated/PegRush.unity to edit/play.
Menu PegRush/2 validates config and deterministic transactions.
Menu PegRush/3 builds without regenerating assets or editing configuration.
Close this project's Editor before batch building:
  powershell -ExecutionPolicy Bypass -File Tools/Build-WebGL.ps1
Run HTTP server from project root:
  powershell -ExecutionPolicy Bypass -File Tools/Serve-WebGL.ps1
Then browse http://127.0.0.1:8080 . Never open index.html using file://.
Deploy the whole Builds/WebGL folder, keeping Build/ and loader paths intact.
Compression is Disabled: no gzip/Brotli Content-Encoding required. Serve .wasm
as application/wasm, .js as JavaScript, .data as application/octet-stream.
A static HTTPS host with WebAssembly/WebGL2 support is sufficient. No server
backend or cross-origin isolation required. Large uncompressed downloads are
an intentional simple-hosting tradeoff. Saves are scoped to the hosting origin.
Fullscreen requires a browser user gesture and browser/device support.

CONTROLS
Mouse click or touch: Play, selectors, Drop, settings, navigation.
Space: one ball per discrete key press; holding does not auto-drop.
Tab/Shift+Tab navigation, Enter activation (InputSystemUIInputModule).
Rows +/- clamp 8..16. Profile cycles Green/Gold/Red. Amount cycles allowed coins.
Rows/profile stay locked until all active balls resolve. Amount applies only to
future balls. Sound/reduced-effects options persist. Free refill only when no
pending balls and wallet below 1 coin. No forced per-ball result popup.

BROWSER METHODS / COVERAGE

REMAINING LIMITATIONS
Browser-local progress is not cloud-synced and can be edited or cleared by the
player. Saves do not survive origin/profile changes or guaranteed private-mode
storage eviction. Unknown save versions reset rather than migrating an unknown
schema. No legacy PegRush save schema existed before Sprint 1.
Performance numbers are short local samples on the stated hardware, not mobile
performance guarantees, long soak tests or memory-leak certification.
Touch emulation does not establish physical-device usability/performance.
Fonts and individual multipliers are necessarily compact at 360 CSS pixels.
Input automation sequences faster than an engine frame can coalesce pointer
positions; real rapid-input checks use discrete press durations/frame spacing.
No cross-browser matrix, installed-app/PWA support or cloud service is included.
