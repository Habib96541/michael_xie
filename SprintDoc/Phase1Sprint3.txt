1. REQUEST AND SPRINT GOAL
--------------------------
Polish the existing game so it looks like a finished casual mobile game rather
than a functional demo. The main requested changes were cooler fonts, coin
sprites, an original game logo, and a cohesive game-style interface. The full
supplied request is appended to this record.

Preserve the playable Mines rules, scoring, saves, daily rewards, progression,
mute, reduced effects, and existing Unity conventions. Keep Phase 1 unchanged.
Preserve Sprint 1 and Sprint 2 documentation.

2. BASELINE INSPECTION
----------------------
Inspected the request, existing runtime UI, tile view, audio/feedback code,
configuration, responsive grid, scene generator, custom Editor verification,
Play Mode smoke tools, scene, and earlier screenshot evidence.

Retained Unity 6000.3.10f1, URP 2D, uGUI/TextMeshPro, the new Input System, the
720x1280 Canvas reference, portrait content fitting, and SafeArea handling.
No third-party Unity package was installed for this sprint.

3. VISUAL IDENTITY
------------------
Replaced the bright prototype-like presentation with a darker treasure-game
palette: midnight indigo backgrounds, restrained cyan accents, warm gold
currency, emerald primary actions, and blue secondary/banking actions.

The main logo uses glossy cyan/ice MINE lettering and gold GRID lettering,
deep indigo depth, a faceted gem, and a grid/mine emblem. It is an original
transparent illustration generated for this project.

The title and home screens show the full logo prominently. Other screens use
a smaller header logo. Duplicate compact branding is hidden on title/home.

Background decoration is subtle and noninteractive. Layered surfaces, rims,
recesses, and shadows give panels and controls a consistent family appearance.

4. TYPOGRAPHY
--------------
Display: Lilita One Regular.
Used for buttons, headings, and prominent numeric values.

Body: Varela Round Regular.
Used for instructions, status, settings, descriptions, and supporting labels.

Both original TTF files are bundled. TextMeshPro SDF assets are generated and
saved in Assets/MineGrid/Fonts. A shared theme supplies the font assets.
The display font falls back to the body font; the body font retains the
existing LiberationSans TMP fallback for exceptional glyph coverage.

Changed most player-facing headings and controls to sentence/title case.
Removed generic COINS prefixes where actual coin illustrations are shown.
Display text uses restrained shadowing. Automatic sizing remains bounded.

Source/license details:
- Lilita One: copyright Juan Montoreano, reserved font name Lilita.
- Varela Round: copyright The Varela Round Project Authors, reserved font names
  Varela and Varela Round.
- Both bundled source licenses are SIL Open Font License 1.1.
- Original fonts were downloaded from the google/fonts repository.
- Full licenses and copyright notices are retained alongside the fonts.
- Original font outlines were not modified.
