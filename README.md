# Egg Drop

A small 3D push-your-luck game in Unity 6000.3.27f2 with URP 17.3 and the new Input System.

Open `Assets/Scenes/EggDrop.unity` and press Play in the editor, then choose Play on the main menu. The `Egg Drop > Open Game Scene` editor menu also opens it. The game supports landscape and portrait layouts.

The main menu includes Play, Sound Settings, and Quit. Quit is available in a built game and disabled in the editor. Sound Settings controls music, effects, and mute; changes carry into gameplay and are saved locally. Gameplay shortcuts are blocked while the menu is open. After collecting or cracking, Main Menu returns to the title screen and resets the egg while retaining the session bank. Starting another round preserves that bank.

## Play

Drop the egg, survive the landing, then choose between collecting your points and attempting a higher floor. Cracking loses the current round's points. Collected points remain in the bank until Play mode or the application ends.

| Action | Keyboard | Pointer or touch |
| --- | --- | --- |
| Drop | Space | Drop Egg |
| Collect | C | Collect |
| New round after collecting or cracking | R | Fresh Egg |
| Mute or unmute | M | Sound On / Off |
| Music and effects levels | Sliders | Sliders |

Floor 1 starts at an 8% chance of cracking. Each floor adds 5.5 percentage points. The random outcome is decided once on physical contact with the landing pad. Impact speed does not determine survival.

After clearing floor `n`, the multiplier is `1 + 0.25n + 0.07n*n`. Round points are 100 times that multiplier, rounded to a whole point. The first safe landing earns 132 points. Clearing all 12 floors earns 1,408 points; collect to bank them.

Dropping and collecting are disabled during a fall and the lift animation. A new round is available after collecting or cracking.

On a failed landing, the shell breaks into ten irregular curved fragments with visible inner surfaces and broken edges. The pieces tumble onto the pad while egg white and yolk spread from the impact point. The effect reuses its fragments and restores them when the next round starts.

## Audio and assets

Eight original audio files cover release, falling air, landing, success, collection, cracking, interface feedback, and a quiet music loop. Music and effects have independent levels. Mute and volume settings are saved locally; gameplay scores are session-only.

All added meshes and sounds were created for this project. No external CC0 assets were needed. See `ASSET_SOURCES.txt` for provenance.

## Project files

- `Assets/Scripts`: round rules, gameplay, physics, interface, stage, and audio.
- `Assets/UI`: UI Toolkit layout, styles, and panel settings.
- `Assets/Art`: original egg meshes and materials.
- `Assets/Audio`: imported WAV files.
- `Assets/Editor`: scene and sound generation used for the initial setup.
- `Assets/Tests`: EditMode rule tests, a PlayMode scene integration test, and a test menu.
- `SprintDocs/Sprint_01.txt`: scope, changes, verification, and open questions.
- `SprintDocs/Sprint_02.txt`: shell fracture, spill, and restart verification.
- `SprintDocs/Sprint_03.txt`: main menu, sound settings, and menu transition checks.

The setup script creates the game scene only when it is absent. It does not overwrite an existing game scene. The original template scene remains available.

`Egg Drop > Upgrade Crack Effect` creates or rebuilds the egg's fracture objects while preserving the rest of the scene. New scenes generated by the setup script include the effect automatically.

## Checks

Use `Egg Drop > Checks > Run Rule Tests` and `Run Scene Test`. In Unity's Test Runner, use EditMode for `EggDrop.Tests` and PlayMode for `EggDrop.PlayModeTests`. Checks cover round rules, closed shell meshes, physical landing, collection, cracking, repeated fracture resets, keyboard controls, mute, sound levels, main-menu actions, blocked gameplay behind the menu, and saved settings across scene reloads.

The installed Unity AI package may report `NoSubscription` while fetching its models. Those editor package errors are unrelated to Egg Drop's scripts or audio and require no AI subscription to play the game.

## WebGL build

Use `Egg Drop > Build WebGL` after exiting Play mode. Install WebGL Build Support for Unity 6000.3.27f2 if it is missing. The command builds the saved `Assets/Scenes/EggDrop.unity` scene into `Builds/WebGL` as a release player. It temporarily selects gzip compression, browser decompression fallback, and 128 MB initial memory, then restores those settings. The build summary is written to `Logs/EggDrop-WebGL-Summary.txt`.

For a local preview, run this command from the Unity project folder:

```powershell
& "C:/Program Files/Unity/Hub/Editor/6000.3.27f2/Editor/Data/PlaybackEngines/WebGLSupport/BuildTools/Emscripten/python/python.exe" -m http.server 8765 --bind 127.0.0.1 --directory "Builds/WebGL"
```

Open `http://127.0.0.1:8765` in a browser. Serve the build over HTTP or HTTPS; opening `index.html` directly from disk does not load the game correctly. Click Play to enter the game and allow browser audio to start. Press Ctrl+C in the server terminal to stop the preview.

To host the game, upload the contents of `Builds/WebGL`, keeping `index.html` at the site root and preserving the `Build` and `TemplateData` folders. The decompression fallback does not require special gzip response headers. Host over HTTPS for a published game.

`Builds/EggDrop-WebGL.zip` contains the packaged player, with `index.html` at its root. The WebGL folder and ZIP are included in Git for delivery; Unity caches, local logs, and other build folders remain ignored. `SprintDocs/Sprint_04.txt` records the release build and browser checks.

The release build passes with no build errors or warnings, and its main menu loads over HTTP. Full browser gameplay, audible playback, and fullscreen behavior still need verification. The embedded test browser showed a fullscreen scaling issue; native Chrome validation was interrupted. Close the browser tab to exit a WebGL session.
