# Juice Dojo

A Unity 6 fruit-slicing game with an illustrated orchard, crooked wooden signs, taped cardboard cards, and a warm garden-menu aesthetic.

## Play

- Open `Assets/Scenes/BackyardDojo.unity` and press **Play**.
- Or launch `Builds/Windows/Fruit Ninja.exe` after building. Keep its accompanying data folder and DLLs together.
- Hold the left mouse button and swipe, or drag a finger on a touchscreen. Click a mode card or swipe through its fruit to start.
- **Esc / P:** pause. **Space / Esc:** resume. **R:** retry from the results screen.

## Modes

- **Classic:** survive as long as possible. Three missed fruit or one sliced bomb ends the round.
- **Arcade:** 60 seconds, escalating waves, combo bonuses, rare critical slices, freeze and fruit-frenzy powerups. Bombs subtract 10 points.
- **Zen:** 90 seconds of fruit with no bombs and no miss penalties.

Slice at least three fruit in one stroke for a square-of-count bonus. High scores are stored separately for each mode. Lifetime fruit, best combos, sound preferences, and blade color persist locally with Unity PlayerPrefs.

## Project

Unity **6000.3.10f1**; uses the project's Universal Render Pipeline, Unity UI, and Input System packages. No additional packages or external services are needed to play. UI is generated from reusable textured paper meshes at runtime. A centered interface sits inside a clipped 1953 × 900 play area (2.17:1), fitted to the device safe area without stretching the artwork or touch coordinates.

- `Assets/FruitNinja/Scripts/FruitNinjaGame.cs`: modes, fruit trajectories, segment-based swipe detection, slicing, effects, sound, menus, and records.
- `Assets/FruitNinja/Scripts/PaperGraphic.cs`: textured cardboard, clipped fruit halves, blade trail, and button feedback.
- `Assets/FruitNinja/Editor/ProjectSetup.cs`: scene setup, Windows build command, and editor verification bridge.

Use **Backyard Dojo → Build Windows player** to rebuild. The editor's **Set up game scene** command recreates the dedicated scene.

## Validation

The two project artwork assets were generated with the built-in `image_gen` tool. Their prompts and saved paths are recorded in `Assets/FruitNinja/ArtGeneration.json`. Textured paper, interface meshes, particles, blade trails, and audio are generated by code.

Lilita One and Lato come from the Google Fonts repository. Their SIL Open Font License files are included beside the font assets.

## Cloudflare web version

Play the deployed game at [fruit-ninja-backyard-dojo.pages.dev](https://fruit-ninja-backyard-dojo.pages.dev/).

The same Unity game can be built for browsers with Unity's **Web Build Support** module installed for 6000.3.10f1. Run `./Tools/build-web.ps1` in PowerShell 7. The script prepares a generated export project in `Library/CloudflareRuntimeProject` from the game scripts, scene, and artwork, using Unity UI and Input System. Excluding unused editor and rendering packages avoids a Collections package compilation incompatibility. The exported game is written to `Builds/WebGL/` with a branded download screen, Brotli-compressed game assets, and Cloudflare Pages response headers.

`Assets/FruitNinja/Editor/CloudflareWebBuild.cs` owns the browser build settings and validates Cloudflare's per-file upload limit. `Assets/WebGLTemplates/BackyardDojo/` contains the browser shell. Preview the exported game with `python Tools/serve_web.py`, which serves the compressed files with the correct headers at `http://127.0.0.1:4173`.

Publish a rebuilt export to the existing Cloudflare Pages project with `./Tools/deploy-cloudflare.ps1` in PowerShell 7. Wrangler uses the local Cloudflare login; credentials are not included in the project or uploaded game. The deployment's verified public URL is recorded in `Artifacts/cloudflare-deployment.json`.

## Staggered launches and repeated cuts (1.2)

Launches use three sections: left, middle, and right. A round starts with two fruit in the middle, then one on each side in random order. Subsequent patterns randomly mix singles and pairs across the sections, with position jitter, randomized fruit types, 0.18–0.28 second pair delays, and 0.44–0.78 second section delays. Difficulty gradually shortens those delays; Arcade frenzy also speeds the sequence up. Bombs occupy their own delayed launch. Pausing freezes the schedule, and restarting clears pending launches.

Each swipe clips the actual fruit polygon at the blade's angle and position. Existing pieces keep their original texture coordinates and clipped outlines, so second and third cuts divide those pieces further. Pieces fall more slowly to allow follow-up cuts. Each extra cut adds one point, while harvest totals, fruit combos, and powerups count only the first cut of the original fruit. A short recut cooldown, minimum chip size, 96-piece limit, and automatic expiration bound repeated-cut work on mobile.
