# Chest Shuffle 3D

A 3D shell-game betting game made with Unity **6000.6.7f1** (built-in render pipeline, no extra packages). Three treasure chests shuffle across a vault stage. Each hides a multiplier between **0.1× and 10×**. Pick one chest, its lid swings open, and your stake is multiplied by the value inside.

Everything is procedural: the chests are modelled from primitives at runtime, the arena and lighting are generated by the editor setup, and the HUD is drawn with IMGUI using the bundled fonts. There are no imported models or prefabs.

## Play

Open the project in Unity **6000.6.7f1**, open `Assets/Scenes/ChestShuffle3D.unity` and press Play.

- **Stake:** pick 10, 20, 50, 100 or 250 coins from the dock. You start with 1,000 coins.
- **Play:** press **PLAY** (or Enter / Space). The stake is taken up front and the three chests swap places four to six times.
- **Pick:** after the shuffle, click a chest or press **1 / 2 / 3** for its lane.
- **Result:** your chest opens first, showing its multiplier. The other two open a moment later so you can see what you missed. Payout = `stake × multiplier`, rounded to whole coins.
- **Again:** press **PLAY AGAIN** or Enter to run another round with the same stake.
- **Bankroll:** the balance persists in `PlayerPrefs`. If it drops below 10 coins the button becomes **TOP UP +500**; the small **RESET** button restores 1,000 coins.

### Multiplier table

Each round draws three **distinct** values from this weighted pool:

| Multiplier | Weight |
| --- | --- |
| 0.1× | 22 |
| 0.2× | 16 |
| 0.5× | 16 |
| 1× | 16 |
| 1.5× | 10 |
| 2× | 8 |
| 3× | 6 |
| 5× | 4 |
| 10× | 2 |

## Presentation

- **3D chests:** plank-and-band construction with a rounded lid on a rear hinge, gold straps, lock plate, side handles and hinges, plus a glowing coin hoard revealed inside.
- **Shuffle:** each swap is a 0.42 s arc — the two chests hop over each other with a sin-curve lift and tilt, one passing just in front of the other, while the third stays put.
- **Picking:** hovering a chest raises it, brightens its gold trim and lights a pulsing gold ring beneath it; the lane number floats above.
- **Reveal:** the chosen chest's lid swings 96° open, its interior light fades in, and the multiplier plate springs up over the chest. A big result punches the camera in, shakes it, and flashes gold for a 10× jackpot.
- **Arena:** polished floor with gold inlays, stone pedestals, a walled vault with glowing strips, hanging lamps, spotlights, fog and drifting dust motes.
- **Responsive:** the camera pulls back and the dock restacks for portrait screens; the HUD is built at a 1440×900 reference and scaled to fit.

## Build

Choose **Chest Shuffle → Set Up Scene** to regenerate the materials, arena and scene, or **Chest Shuffle → Validate Rules** for the deterministic rule checks. **Chest Shuffle → Build WebGL** writes the regular responsive build to `Build/WebGL` and a self-contained `Build/WebGL/ChestShuffle3D.html`. Open that single HTML file directly in a modern desktop browser to play without a server. The regular multi-file WebGL build still needs to be served over HTTP.

Batch mode:

```bash
"/c/Program Files/Unity/Hub/Editor/6000.6.7f1/Editor/Unity.exe" \
  -batchmode -quit -projectPath "<path>/ChestShuffle3D" \
  -executeMethod ProjectSetup.Setup \
  -logFile "<path>/ChestShuffle3D/setup.log"

"/c/Program Files/Unity/Hub/Editor/6000.6.7f1/Editor/Unity.exe" \
  -batchmode -quit -projectPath "<path>/ChestShuffle3D" \
  -executeMethod ProjectSetup.BuildWebGL \
  -logFile "<path>/ChestShuffle3D/build.log"
```

`ProjectSetup.Setup` creates `Assets/Resources/Materials/*.mat`, builds `Assets/Scenes/ChestShuffle3D.unity`, applies the player settings and then runs the rule checks.

## Project layout

- `Assets/Scripts/ChestShuffleGame.cs` — round phases, stake handling, shuffle plan and motion, picking, payout, camera framing, saved bankroll.
- `Assets/Scripts/Chest3D.cs` — procedural chest model, hinged lid, trim glow, hover lift, selection ring, interior light.
- `Assets/Scripts/ChestHud.cs` — HUD layout, balance count-up, stake chips, play button, phase copy, world-anchored chest badges and multiplier plates.
- `Assets/Scripts/MultiplierTable.cs` — weighted distinct rolls, payout rounding, labels and verdicts.
- `Assets/Scripts/MaterialLibrary.cs` — shared material palette with procedural fallbacks.
- `Assets/Scripts/MeshUtils.cs` — ring mesh for floor inlays and chest rings.
- `Assets/Editor/ProjectSetup.cs` — materials, materials assets, arena scene, validation and WebGL build.
- `Assets/Resources/Fonts/` — Archivo Black and Barlow (SIL Open Font License; license files included).
